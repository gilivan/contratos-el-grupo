REQUISITOS
──────────
• Python 3.8 o superior  →  python.org/downloads
• Conexión a internet solo la primera vez (para instalar librerías)

INSTALACIÓN (solo la primera vez)
──────────────────────────────────
1. Abre una terminal (cmd en Windows, Terminal en Mac)
2. Navega a la carpeta de este proyecto:
      cd ruta/a/contratos-web
3. Instala las librerías necesarias:
      pip install flask python-docx

CÓMO USARLO
───────────
1. En la terminal, dentro de la carpeta del proyecto ejecuta:
      python app.py

2. Abre tu navegador y ve a:
      http://localhost:5000

3. Llena el formulario y haz clic en "Generar Contrato Word"

4. El contrato se descarga automáticamente en tu carpeta de Descargas,
   con todos los campos diligenciados resaltados en amarillo.

5. Para detener el servidor: presiona Ctrl+C en la terminal.

COMPARTIR CON OTROS USUARIOS
─────────────────────────────
• Envía la carpeta completa "contratos-web" por correo o Drive.
• Cualquier persona con Python instalado puede ejecutarla.
• No requiere cuenta de Claude ni ningún servicio externo.
